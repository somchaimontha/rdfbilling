# RDF Expense System — ระบบบริหารรายจ่าย มูลนิธิ RDF (v4.12)

แอปพลิเคชันระบบบันทึกรายจ่ายและส่งเบิกของ มูลนิธิ Dr. Robert Dyckerhoff เวอร์ชัน 4.12 รองรับหลายสถาบัน และเชื่อมต่อฐานข้อมูลคลาวด์แบบ Real-time ผ่าน Google Apps Script (GAS) API, Google Sheets และ Google Drive

---

## 1. คุณลักษณะเด่นของระบบ (Key Features)

### 1.1 การเชื่อมต่อระบบคลาวด์ (GAS Cloud Integration)
* ระบบเปลี่ยนการจัดเก็บข้อมูลจากบราวเซอร์ท้องถิ่น (LocalStorage) ไปพึ่งพาคลาวด์ผ่าน **Google Sheets API** ทำให้ข้อมูลมีความปลอดภัย ทนทาน และแชร์ใช้งานร่วมกันได้แบบเรียลไทม์
* ดึงข้อมูลโครงสร้างโครงการ (Projects), หมวดหมู่รายจ่าย (Categories), ผู้ขาย (Vendors), แหล่งเงิน (Fund Sources) และรายการบิลแบบสดใหม่เสมอ

### 1.2 โหมดการทำงานบนหน้าจอขนาดเล็กและมือถือ (Mobile Responsive UX)
* **ยุบแถบเมนูด้านซ้าย (Sidebar Collapse):** ปุ่มเมนูสามขีดสีเขียวมุมบนสุด ช่วยให้ผู้ใช้สามารถกดคลิกเพื่อยุบ/เปิดแถบเมนูด้านซ้ายได้อิสระบนหน้าจอเดสก์ท็อป ช่วยขยายพื้นที่ตารางบันทึกข้อมูลให้กว้างเต็มตา 100%
* **แถบเครื่องมือด่วนตาราง (Table Actions Bar):** มีแผงปุ่มลัดสีเขียว ฟ้า เทา ในหน้าตารางบันทึกบิล เพื่อเปิดหน้าต่างกรอกข้อมูล (Modals) ป๊อปอัปกรอกรายจ่าย แทนการป้อนข้อมูลบน inline table row ท้ายตารางที่แคบและล้นจอ

### 1.3 ฟังก์ชัน "เพิ่มบิลโครงการเพิ่มเติม" (Add Additional Project Bill) 🌟
* เพิ่มปุ่ม **"เพิ่มบิลโครงการเพิ่มเติม"** (ปุ่มสไตล์ `.btn-accent` สีฟ้า Sky Blue)
* เมื่อคลิก ระบบจะสลับช่องเลือกโครงการในหน้าต่างเพิ่มรายการเป็นกล่องป้อนข้อความให้อัตโนมัติ ให้คุณระบุชื่อโครงการ/กิจกรรมเสริมตัวใหม่ลงไปได้ทันที
* เมื่อบันทึก ระบบจะส่งคำสั่งสร้างโครงการใหม่ผ่าน API ไปยัง Google Sheets จากนั้นรีเฟรชระบบแล้วผูกรายการรายจ่ายนี้เข้ากับโครงการนั้นทันทีในขั้นตอนเดียว

### 1.4 ตัวกรองโครงการและสะกดภาษาไทยขณะพิมพ์รายงาน A4 (A4 Print Filter)
* เพิ่มกล่อง "ตัวกรองโครงการ" ในแผงตั้งค่าการพิมพ์ใบขอเบิกเงินรูปแบบ A4
* ยอดเงินสรุปสะสมและคำอ่านตัวสะกดภาษาไทยท้ายหน้าใบเบิกเงิน จะทำการคำนวณและปรับเปลี่ยนใหม่ตามเงื่อนไขโครงการที่เลือกคัดกรองแบบ Real-time ทันที

### 1.5 สรุปรายจ่ายรายปีบน Dashboard (Annual Dashboard Summary)
* แสดงข้อมูลครบ 12 เดือนของปีที่เลือก พร้อมจำนวนบิล ยอดเบิกมูลนิธิ ยอดไม่เบิก และยอดรวมทั้งปี
* กดชื่อเดือนในตารางเพื่อเปลี่ยนเดือนที่กำลังแสดงในระบบได้ทันที
* ใช้ตัวกรองรูปแบบการคำนวณเดียวกับ Dashboard และไม่นับรายการที่ยกเลิก

### 1.6 รอบบัญชีตามเวลาไทย (Bangkok Accounting Period)
* เมื่อเปิดหน้าใหม่ ระบบเลือกเดือนและปีปัจจุบันตามเขตเวลา `Asia/Bangkok` อัตโนมัติ
* ตัวเลือกเดือนหลักและหน้าสรุปค่าอาหารใช้รอบบัญชีเดียวกัน เพื่อลดการบันทึกข้อมูลผิดเดือน

### 1.7 การแนบหลักฐานและถ่ายภาพเอกสาร (Evidence Attachments)
* แสดงข้อมูลบิลให้ตรวจสอบก่อนแนบไฟล์ และมีคิวตัวอย่างไฟล์ก่อนกดยืนยันอัปโหลด
* รองรับการเลือกหลายไฟล์ ลากวาง วางจาก Clipboard และถ่ายภาพด้วยกล้องหลังบนอุปกรณ์ที่รองรับ
* รองรับไฟล์ JPG, PNG, WEBP, PDF, XLSX, DOCX และ CSV พร้อมตัวเลือกปรับแสง ลดเงา และเพิ่มความคมชัดของภาพเอกสาร
* แสดงภาพตัวอย่างจาก Google Drive และตรวจสอบความถูกต้องของไฟล์ด้วย SHA-256 ก่อนจัดเก็บข้อมูลประกอบ

### 1.8 ค่าอาหารประจำเดือนและรายงานตรวจสอบ (Monthly Food Expenses)
* หน้าสรุปค่าอาหารใช้ข้อมูลรอบเดือนเดียวกับหน้าบันทึก สามารถแก้ไขรายการและเปิดหลักฐานได้จากตารางโดยตรง
* ตารางสรุปแสดงยอดรวม ยุบ/ขยายรายการ และคงรูปแบบคอลัมน์แบบกระชับพร้อมเลื่อนแนวนอนบนหน้าจอแคบ
* รายงานค่าอาหาร PDF รูปแบบ A4 แนวนอนแบ่งหน้าละ 14 รายการ พร้อมยอดยกมา ยอดยกไป ยอดรวมทั้งสิ้น และ QR Code สำหรับตรวจสอบทุกหน้า

### 1.9 เอกสารรับเงินทุนประจำเดือน (Fund Receipts)
* จัดการจำนวนเงิน ไฟล์เอกสาร และหมายเหตุในหน้าต่างเดียว พร้อมแสดงข้อมูลทันทีหลังบันทึก
* รองรับการถ่ายภาพ เลือกไฟล์ ลากวาง และวางจาก Clipboard สำหรับไฟล์ JPG, PNG, WEBP และ PDF
* ปรับรูปแบบเดือนจากข้อมูลเดิมใน Google Sheets ให้เป็นมาตรฐานเดียวกัน และโหลดเอกสารตามปีที่บันทึกได้ถูกต้อง

### 1.10 ศูนย์รายงานประสิทธิภาพสูง (Report Center)
* ใช้ข้อมูลรายเดือนและ Preview PDF จาก Cache เมื่อการตั้งค่าไม่เปลี่ยน ลดการเรียก Apps Script และการสร้างไฟล์ซ้ำ
* ล้าง Cache อัตโนมัติหลังบันทึกข้อมูล พร้อมปุ่มรีเฟรชข้อมูลจากฐานข้อมูลและเวลาอัปเดตล่าสุด
* ป้องกันการกดส่งออกซ้ำระหว่างสร้าง CSV, Excel และ PDF พร้อมแสดงสถานะการทำงานให้ผู้ใช้ทราบ
* แสดงเปอร์เซ็นต์และจำนวนรายการจริงระหว่างโหลดหลักฐาน ประมวลผลรูป และจัดหน้า PDF พร้อมปรับเวลารอตามจำนวนรายการ (สูงสุด 5 นาที) เพื่อไม่ตัดการทำงานที่ยังดำเนินอยู่หลัง 45 วินาที
* หน้าแรกของ PDF สรุปทุกหัวข้อ ส่วนค่าอาหารและโครงการเพิ่มเติมที่มีมากกว่า 5 รายการจะแสดงจำนวน หมวดหมู่ และยอดรวมแบบย่อเพื่อให้อยู่ในหน้าเดียว
* หัวข้อหลักแต่ละประเภทเริ่มหน้าใหม่ ส่วนหน้าหลักฐานใช้คำอธิบายแบบความเรียงและวางรูปแรกไว้หน้าเดียวกัน พร้อมย่อรูปตามพื้นที่พิมพ์เพื่อไม่ให้ข้อความหรือรูปตกขอบ
* หลักฐานเรียงตามเลขบิล/ใบเสร็จแบบตัวเลขธรรมชาติ หรือตามลำดับรายการที่ผู้ใช้เลือก และรูปหลักฐานชิ้นถัดไปเริ่มหน้าใหม่พร้อมเลขอ้างอิง
* เมนูเลือกหัวข้อรายงานรองรับคอลัมน์ **รายละเอียดรายการ** และสร้างจากทะเบียนหัวข้อกลางเดียวกับ Preview, PDF, CSV/Excel, ป้ายจำนวน และ Template เพื่อรองรับหัวข้อใหม่ในอนาคต
* ตั้งค่าระยะขอบรายงานด้านบน ล่าง ซ้าย และขวาเป็นมิลลิเมตรได้จากเมนูรูปแบบรายงาน โดยค่าเริ่มต้นเว้นหัวกระดาษหน้าที่ 2 เป็นต้นไปให้อ่านง่ายและบันทึกค่าไว้ในอุปกรณ์/Template
* การลงชื่อใต้เอกสารแยกช่องชื่อ-สกุล ตำแหน่ง และหน้าที่ลงนาม เพิ่มผู้ลงนามได้สูงสุด 9 คน จัด PDF แถวละ 3 คนโดยแถวสุดท้ายชิดขวา และเลือกลงนามหน้าแรก หน้าสุดท้าย หรือทุกหน้าได้ตามเงื่อนไขโดยไม่แสดงซ้ำในหน้าเดียว
* เลือกลงนามใต้หัวข้อรายการหลักได้หลายหัวข้อจากทะเบียนรายงานกลาง พร้อมแสดงรายชื่อโครงการที่มีรายการจริงในเดือนรายงานโดยอัตโนมัติ และปิดตัวเลือกที่ซ้ำกับ “ทุกหน้า” หรือหัวข้อที่ไม่ได้ส่งออก
* เลือกรูปแบบหลักฐานระดับรายงานและกำหนดทับรายหัวข้อได้ ทั้ง A4 แนวตั้ง/แนวนอน, 1/2 หลักฐานต่อหน้า และเรียงบน–ล่าง/ซ้าย–ขวา พร้อมตัวอย่าง A4 แบบสด
* Preview และ PDF ใช้ค่าจัดหน้าชุดเดียวกัน รองรับหลายแนวกระดาษในไฟล์เดียว และบันทึกค่าไว้ในอุปกรณ์กับ Template รายงานโดยไม่เพิ่มตารางฐานข้อมูลใหม่

### 1.11 กฎถาวรสำหรับการจัดหน้าเอกสาร (Document Layout Guardrails)
* ทุกครั้งที่เพิ่มหัวข้อหรือคอลัมน์รายงาน ต้องคำนวณจากความกว้างกระดาษหลังหักระยะขอบ ห้ามกำหนดตารางให้กว้างเกินพื้นที่พิมพ์
* หากคอลัมน์เกินพื้นที่ ให้คงข้อมูลสำคัญในแถวหลักและย้ายข้อมูลส่วนเกินลงแถวรายละเอียดเต็มความกว้างโดยอัตโนมัติ ห้ามบีบตัวอักษรจนอ่านไม่ได้
* ตาราง “รายการบิลประจำเดือน” ใช้ลำดับคอลัมน์มาตรฐาน: ลำดับ, เลขบิล, วันที่, เล่มที่/เลขที่ใบเสร็จ, รอบบันทึก, ผู้ขาย, รายละเอียดรายการ, โครงการ, หมวดหมู่, หลักฐาน, ยอดรวม และประเภทเบิก โดยให้หลักฐานอยู่ก่อนยอดรวมและให้รายละเอียดรายการกว้างกว่าคอลัมน์ทั่วไป
* ส่วน “สรุปรายการทั้งหมด” ต้องแยกตารางตามหัวข้อหลัก รายการบิล/บิลแนบ/โครงการเพิ่มเติมแสดงรายละเอียดรายการย่อย ค่าอาหารแสดงแบบย่อเป็นจำนวนรายการ และทุกตารางต้องมีแถวยอดรวมด้านล่าง
* แถวรายละเอียดเพิ่มเติมที่มีหมวดหมู่ จำนวนหลักฐาน และประเภทเบิกเหมือนกันทุกรายการ ให้แสดงเป็น “รายละเอียดร่วม” ใต้รายการสุดท้ายเพียงครั้งเดียว หากค่าแตกต่างกันให้แสดงใต้รายการที่เกี่ยวข้อง
* ข้อความภาษาไทยต้องตัดบรรทัดเฉพาะขอบคำด้วย `Intl.Segmenter` ห้ามเติมช่องว่างกลางคำ ห้ามแบ่งพยัญชนะ/สระ และห้ามใช้ `U+00AD`, `U+200B` หรืออักขระซ่อนอื่นที่ทำให้แสดงผลหรือคัดลอกเป็นคำแตก เช่น `ก าร` หรือ `คอมพิวเต อร์`
* การแก้ตัวสร้าง PDF ทุกครั้งต้องผ่าน Regression Test เรื่องความกว้างตาราง การขึ้นบรรทัดภาษาไทย ระยะขอบ และข้อความคัดลอกก่อนเผยแพร่
* เอกสาร PDF รักษาข้อความภาษาไทยต้นฉบับโดยไม่แทรกอักขระช่วยตัดคำที่ทำให้ข้อความคัดลอกเพี้ยน และแสดง QR ตรวจสอบขนาดเล็กพร้อมเลขเอกสาร/รหัสตรวจสอบในหัวกระดาษทุกหน้าตั้งแต่หน้าที่ 2
* รูปหลักฐานที่จัดคู่ต้องรักษาสัดส่วน แสดงคำอธิบายของแต่ละรายการ และกลับสู่แนวกระดาษหลักเมื่อเริ่มหัวข้อถัดไป ส่วน PDF/ไฟล์เอกสารที่ยังฝังตรงไม่ได้ให้แสดงลิงก์ต้นฉบับอย่างชัดเจนโดยไม่อ้างว่าฝังครบทุกหน้า

### 1.12 ขอบเขตสถาบันและบทบาทผู้ใช้ (Institution Access Control)
* รองรับ 3 ขอบเขตข้อมูลหลัก: **VC — วิทยาลัยการอาชีพแม่สะเรียง**, **MBS — โรงเรียนแม่สะเรียงบริพัตร์** และ **OFFICE — สำนักงาน** โดยข้อมูลเดิมของระบบอยู่ใน `ORG001 / VC`
* Manager, Staff และ Viewer ถูกกำหนดสถาบันที่รับผิดชอบหนึ่งแห่ง และบริการฝั่ง Apps Script ตรวจ `organization_id` ทุกครั้ง ไม่อาศัยเพียงการซ่อนข้อมูลในหน้าเว็บ
* Admin เข้าถึงทุกสถาบันและเลือก “สถาบันที่กำลังบันทึก” จากส่วนหัวระบบ ค่านี้ใช้กับบิล บิลแนบ ค่าอาหาร เอกสารรับเงินทุน โครงการ แหล่งเงิน และตัวกรองรายงานเริ่มต้น
* Permission Matrix: Admin จัดการทั้งหมด; Manager เพิ่ม/แก้ไข/อนุมัติ/ปฏิเสธ/คืนเงินและลบรายการในสถาบันตน; Staff เพิ่ม/แก้ไขและจัดทำใบเบิกโดยลบหรืออนุมัติไม่ได้; Viewer ดูข้อมูลและรายงานอย่างเดียว
* หน้าจัดการผู้ใช้แสดง “สถาบันที่กำลังบันทึก” ของแต่ละบัญชี ค้นหาด้วยชื่อ/รหัสสถาบันได้ และ Admin เปลี่ยนสถาบันรายผู้ใช้ได้โดยตรงจากตารางหลังยืนยันรายการ
* ฟอร์มเพิ่มผู้ใช้แสดงตัวเลือกสถาบันเสมอแม้ระบบมีเพียงหนึ่งสถาบัน และเลือกค่าเริ่มต้นให้อัตโนมัติเพื่อไม่ส่ง `organizationId` ว่าง
* การตั้งหรือเปลี่ยนรหัสผ่านตรวจแบบสด: 12–128 ตัวอักษร, A–Z, a–z, ตัวเลข, อักขระพิเศษ, ไม่ซ้ำข้อมูลบัญชี/รหัสยอดนิยม และต้องยืนยันรหัสผ่านตรงกัน
* Google Login รองรับ Gmail และ Google Workspace โดยจับคู่จากอีเมลที่ Admin กำหนดในบัญชี ตรวจรูปแบบและความซ้ำทั้งหน้าเว็บ/Apps Script และไม่เปิดสมัครผู้ใช้อัตโนมัติ
* เมนู **สถาบัน / สถานที่** เป็นทะเบียนกลางสำหรับเพิ่มและแก้ไขชื่อ รหัสย่อ ที่อยู่ เบอร์ติดต่อ และผู้บริหาร เมื่อบันทึกหรือกดซิงก์ ระบบจะอัปเดตตัวเลือกส่วนหัว ผู้ใช้ แบบฟอร์ม โครงการ แหล่งเงิน และตัวกรองรายงานจากข้อมูลชุดเดียวกัน
* ป้องกันรหัส/ชื่อสถาบันซ้ำ ห้ามปิดสถานที่สุดท้าย และห้ามปิดรายการที่ยังผูกกับผู้ใช้งานที่เปิดใช้งาน เพื่อรักษาความสัมพันธ์ของข้อมูลเดิม

- ปรับหน้าหลักฐานใบเสร็จจากตารางเป็นคำอธิบายแบบความเรียง หัวข้อหนา/ค่าปกติ และวางคำอธิบายกับรูปแรกไว้หน้าเดียวกัน ส่วนรูปถัดไปขึ้นหน้าใหม่พร้อมเลขอ้างอิง
- ปรับขนาดรูปหลักฐานตามพื้นที่แนวตั้งที่เหลือของหน้ากระดาษ รักษาข้อความภาษาไทยให้คัดลอกได้ตรงต้นฉบับ และเรียงตามเลขบิล/ใบเสร็จหรือลำดับรายการ

- เพิ่มตัวป้องกันตารางล้นกระดาษ โดยจำกัดคอลัมน์หลักตามแนวกระดาษ คำนวณความกว้างจากพื้นที่พิมพ์จริง และย้ายคอลัมน์ที่เพิ่มเกินไปลงแถวรายละเอียดเต็มความกว้าง
- เพิ่มการตัดบรรทัดภาษาไทยตามขอบคำโดยไม่แทรกช่องว่าง/อักขระซ่อนกลางคำ พร้อม Regression Test สำหรับคำว่า `การ`, `คอมพิวเตอร์` และคอลัมน์ใหม่ในอนาคต
