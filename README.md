# RDF Expense System — ระบบบริหารรายจ่าย มูลนิธิ RDF (v4.3)

แอปพลิเคชันระบบบันทึกรายจ่ายและส่งเบิกของ มูลนิธิ Dr. Robert Dyckerhoff (วิทยาลัยการอาชีพแม่สะเรียง) เวอร์ชัน 4.3 เชื่อมต่อฐานข้อมูลคลาวด์แบบ Real-time ผ่าน Google Apps Script (GAS) API, Google Sheets และ Google Drive

---

## 1. คุณลักษณะเด่นของระบบ (Key Features)

### 1.1 การเชื่อมต่อระบบคลาวด์ (GAS Cloud Integration)
* ระบบเปลี่ยนการจัดเก็บข้อมูลจากบราวเซอร์ท้องถิ่น (LocalStorage) ไปพึ่งพาคลาวด์ผ่าน **Google Sheets API** ทำให้ข้อมูลมีความปลอดภัย ทนทาน และแชร์ใช้งานร่วมกันได้แบบเรียลไทม์
* ดึงข้อมูลโครงสร้างโครงการ (Projects), หมวดหมู่รายจ่าย (Categories), ผู้ขาย (Vendors), แหล่งเงิน (Fund Sources) และรายการบิลแบบสดใหม่เสมอ

### 1.2 โหมดการทำงานบนหน้าจอขนาดเล็กและมือถือ (Mobile Responsive UX)
* **ยุบแถบเมนูด้านซ้าย (Sidebar Collapse):** ปุ่มเมนูสามขีดสีเขียวมุมบนสุด ช่วยให้ผู้ใช้สามารถกดคลิกเพื่อยุบ/เปิดแถบเมนูด้านซ้ายได้อิสระบนหน้าจอเดสก์ท็อป ช่วยขยายพื้นที่ตารางบันทึกข้อมูลให้กว้างเต็มตา 100%
* **แถบเครื่องมือด่วนตาราง (Table Actions Bar):** มีแผงปุ่มลัดสีเขียว ฟ้า เทา ในหน้าตารางบันทึกบิล เพื่อเปิดหน้าต่างกรอกข้อมูล (Modals) ป๊อปอัปกรอกรายจ่าย แทนการป้อนข้อมูลบน inline table row ท้ายตารางที่แคบและล้นจอ

### 1.3 ฟังก์ชัน "เพิ่มบิลโครงการเพิ่มเติม" (Add Additional Project Bill) 🌟
* เพิ่มปุ่ม **"เพิ่มบิลโครงการเพิ่มเติม"** (ปุ่มสไตล์ `.btn-accent` สีฟ้า Sky Blue)
* เมื่อคลิก ระบบจะสลับช่องเลือกโครงการในหน้าต่างเพิ่มรายการเป็นกล่องป้อนข้อความให้อัตโนมัติ ให้คุณระบุชื่อโครงการ/กิจกรรมเสริมตัวใหม่ลงไปได้ทันที
* เมื่อบันทึก ระบบจะส่งคำสั่งสร้างโครงการใหม่ผ่าน API ไปยัง Google Sheets จากนั้นรีเฟรชระบบแล้วผูกรายการรายจ่ายนี้เข้ากับโครงการนั้นทันทีในขั้นตอนเดียว

### 1.4 ตัวกรองโครงการและสะกดภาษาไทยขณะพิมพ์รายงาน A4 (A4 Print Filter)
* เพิ่มกล่อง "ตัวกรองโครงการ" ในแผงตั้งค่าการพิมพ์ใบขอเบิกเงินรูปแบบ A4
* ยอดเงินสรุปสะสมและคำอ่านตัวสะกดภาษาไทยท้ายหน้าใบเบิกเงิน จะทำการคำนวณและปรับเปลี่ยนใหม่ตามเงื่อนไขโครงการที่เลือกคัดกรองแบบ Real-time ทันที

### 1.5 สรุปรายจ่ายรายปีบน Dashboard (Annual Dashboard Summary)
* แสดงข้อมูลครบ 12 เดือนของปีที่เลือก พร้อมจำนวนบิล ยอดเบิกมูลนิธิ ยอดไม่เบิก และยอดรวมทั้งปี
* กดชื่อเดือนในตารางเพื่อเปลี่ยนเดือนที่กำลังแสดงในระบบได้ทันที
* ใช้ตัวกรองรูปแบบการคำนวณเดียวกับ Dashboard และไม่นับรายการที่ยกเลิก

### 1.6 รอบบัญชีตามเวลาไทย (Bangkok Accounting Period)
* เมื่อเปิดหน้าใหม่ ระบบเลือกเดือนและปีปัจจุบันตามเขตเวลา `Asia/Bangkok` อัตโนมัติ
* ตัวเลือกเดือนหลักและหน้าสรุปค่าอาหารใช้รอบบัญชีเดียวกัน เพื่อลดการบันทึกข้อมูลผิดเดือน

### 1.7 การแนบหลักฐานและถ่ายภาพเอกสาร (Evidence Attachments)
* แสดงข้อมูลบิลให้ตรวจสอบก่อนแนบไฟล์ และมีคิวตัวอย่างไฟล์ก่อนกดยืนยันอัปโหลด
* รองรับการเลือกหลายไฟล์ ลากวาง วางจาก Clipboard และถ่ายภาพด้วยกล้องหลังบนอุปกรณ์ที่รองรับ
* รองรับไฟล์ JPG, PNG, WEBP, PDF, XLSX, DOCX และ CSV พร้อมตัวเลือกปรับแสง ลดเงา และเพิ่มความคมชัดของภาพเอกสาร
* แสดงภาพตัวอย่างจาก Google Drive และตรวจสอบความถูกต้องของไฟล์ด้วย SHA-256 ก่อนจัดเก็บข้อมูลประกอบ

## 2. โครงสร้างไฟล์ในระบบ (Project Directory Structure)

```text
rdf-billing-app/
├── backend/            # Google Apps Script API และบริการเชื่อมต่อ Google Sheets/Drive
├── fonts/              # ฟอนต์ Sarabun สำหรับหน้าเว็บและเอกสาร
├── tests/              # ชุดทดสอบการโหลดข้อมูล รายงาน สิทธิ์ และ workflow รายจ่าย
├── index.html          # โครงสร้างหน้าเว็บ SPA, Dashboard, ตารางข้อมูล และ Modals
├── style.css           # ธีม UI และ Responsive Layout
├── app.js              # State, Event Handlers, API Client และ Business Logic ฝั่งหน้าเว็บ
├── thai-baht.js        # ตัวแปลงจำนวนเงินเป็นคำอ่านภาษาไทย
├── local-dev-server.js # Local Server และ Proxy ไปยัง GAS API
├── preflight-check.js  # ตรวจ Syntax, HTML และความครบถ้วนของ API/Permission ก่อนเผยแพร่
└── package.json        # คำสั่งติดตั้งและทดสอบโครงการ
```

## 3. ข้อมูลการเข้าใช้งานและการพัฒนาต่อ (Development & Access)

* **ความต้องการขั้นต่ำ (Dependencies):** เปิดไฟล์ `index.html` บนเว็บบราวเซอร์ที่เชื่อมต่ออินเทอร์เน็ต (เพื่อส่งขอข้อมูล API และเรียกใช้ชุดไอคอน Lucide Icons และ Chart.js)
* **บัญชีผู้ใช้ทดสอบเริ่มต้น:**
  * **Username:** `admin`
  * **Password:** `<CHANGE_ME_ADMIN_PASSWORD>` (ตั้งค่าจริงใน Google Sheets ผู้ดูแลระบบ ไม่เก็บไว้ในโค้ด)
* **ข้อมูล API คลาวด์:**
  * **Spreadsheet ID:** `<YOUR_SPREADSHEET_ID>`
  * **Apps Script Web App URL:** `<YOUR_APPS_SCRIPT_WEB_APP_URL>`
* **ติดตั้ง Dependencies:** `npm install`
* **รันในเครื่อง:** `node local-dev-server.js` แล้วเปิด `http://localhost:8081`
* **ตรวจสอบก่อนเผยแพร่:** `npm test` (รัน Preflight และชุดทดสอบทั้งหมด)
